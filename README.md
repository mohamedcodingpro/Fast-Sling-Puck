Fast Sling Puck Game
Description
The Fast Sling Puck Game is a two-player game where players flick pucks towards their opponent's goal using a sling-like mechanism. The goal is to score by getting pucks into the opponent's goal while defending your own.

This game features a simple, fun, and interactive design with a wooden theme, and includes sound effects for actions like slinging the puck and winning the game.

Features
Two-player game mode.
Interactive game board with wooden design.
Sound effects for flicking pucks and winning the game.
Scoreboard to track player scores.
Restart option to reset the game after each round.
How to Play
Objective: The goal of the game is to be the first player to get all of your pucks into the opponent's goal.
Gameplay:
Player 1 and Player 2 each start with 5 pucks.
Players take turns flicking pucks from their side of the board towards the opponent’s goal.
To flick a puck, simply click on a puck in the puck area.
The puck will "sling" towards the opponent's goal.
If the puck lands in the opponent's goal, you score a point.
Winning: The first player to get all of their pucks into the opponent's goal wins the round.
Restart: Press the "Restart Game" button to start a new round.
